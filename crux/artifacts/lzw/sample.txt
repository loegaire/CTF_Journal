--- ARCHIVE OFFICE BULLETIN, REVISION 4 ---

Reminder to all staff: every tape is now written with the new vault codec. Each tape gets its own symbol table, so a table that works on one tape will be useless on the next. The table is reshuffled Fisher-Yates style, walking down from the last slot, and the random numbers come from a small xorshift-family generator. The generator is seeded with the index key printed in the tape log. For this tape the index key is, in hex: 0745B6.

The codec writes a leading reset code, then data codes, then an end code, and packs the bits from the low end of each byte. Code widths start out wider than the older codec did, because the vault ledger grew; the width grows again as the table fills. The first slots of the table are reserved for the control codes, so literal symbols are not the first thing in the table any more. Do not ask the vault clerks about the details; the clerks only keep the keys, not the codec.

Please keep this bulletin with the tape. If the bulletin is lost, the tape is lost. If the tape is lost, see the first paragraph of this very bulletin about who gets blamed, and remember that the cheerful intern who always fills out the log forgot to write the key on file-07, file-08 and file-10.

Shelf inventory for the quarter, for reference only: file-01 through file-06 are on shelf A-2; file-07 through file-10 are on shelf B-6; file-11 and file-12 are in the old cabinet, which still sticks. Anyone who finds a cabinet that does not stick is asked to report it immediately, because it is surely the wrong cabinet. End of bulletin.
